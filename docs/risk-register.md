# Risk Register

| Risk                                                                            | Impact                                                        | Mitigation                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Gmail API rate limits could throttle the connector                              | Delayed/missed bill detection                                 | Exponential backoff + configurable polling interval                                                                                                                                                                                                                                                                      |
| Email parsing false positives could misclassify a bill                          | Noisy/incorrect alerts erode trust in the digest              | Confidence threshold on extraction + manual review queue before a low-confidence event fires a notification -- implemented: `RulesEngineService.evaluate` routes any event with `confidence: 'low'` to a review queue (`EventLog.needsReview`) instead of notifying; households approve/dismiss from `/dashboard/review` |
| Refresh token theft/replay                                                      | Account takeover                                              | Rotation on every use + reuse detection revokes the whole token family (§10, ADR 0004)                                                                                                                                                                                                                                   |
| Free-tier hosts (Render/Vercel/Neon/Upstash) impose cold starts and hard limits | Slow or failed daily digest run                               | Daily cron cadence tolerates cold starts; documented upgrade path in ARCHITECTURE.md §18.6 if load grows                                                                                                                                                                                                                 |
| WhatsApp webhook spoofing                                                       | Fake inbound messages processed as real commands              | `X-Hub-Signature-256` HMAC verification on every inbound webhook (§18.5)                                                                                                                                                                                                                                                 |
| Malformed connector payload corrupts downstream state                           | Bad domain event silently propagates through the rules engine | Every event validated with `zod` at the connector/queue boundary (§6)                                                                                                                                                                                                                                                    |
