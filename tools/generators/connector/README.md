# Connector generator (planned)

Custom Nx generator: `nx g @cairn/tools:connector <name>` — scaffolds a new `libs/connectors/<name>` lib with the `Connector` interface stub, a fixture-based spec file, correct Nx tags, and an auto-registration entry in the worker's connector registry.

Not yet implemented — see `ARCHITECTURE.md` §17.7 and `docs/roadmap.md` (M2/M6).
